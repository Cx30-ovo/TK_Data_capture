# 账号风格档案 v0.2：紧凑展示与扩大样本

本轮针对长段落、可视化不足、卡片不统一和40篇样本过少进行改进。

## 页面

- 顶部整合分析记录与更新按钮，样本覆盖用环形图展示，旧档案实际篇数与当前可分析篇数分开。
- 概览为样本主题条形图及五维摘要卡；统一边框、间距、图标、层级和主题色。
- 模型返回一句摘要及1—3个短标签，长分析默认折叠；代表作品按条翻阅，不一次铺开全部引用。
- 点击维度后在同一详情区展开完整分析与依据，不弹新模态。
- v0.1原始段落仅以带省略号的短预览展示，原文仍可展开；不伪造旧版摘要或主题分布。
- 历史档案保留；“扩大样本并更新”由用户点击后才调用模型。

## 样本和主题图

- 单次上限40→500篇；最近5000篇有效作品内按时间等距抽样。
- 送模型的JSON正文上限48000个Unicode字符，超限时减少样本、不截断标题。
- 仅传作品ID及完整清理后标题，移除重复的时间、哈希等模型输入元数据；这些依据仍由服务端保存。
- 当前厦门广电近30天核对：502篇可用，预计送500篇，输入44034字符，覆盖99.6%。这是可分析量，不是已完成的新版推断结果。
- 模型返回最多6个互斥主主题及与输入同序的逐篇类别下标。
- 严格校验数组长度、整数类型、下标范围、标签唯一性；服务端计算每类篇数并保留作品ID。不能用模型宣称的百分比直接画图。
- 图表标明“模型逐篇归类”和仅代表分析样本，不宣称全账号内容占比或事实核验。
- 分类无效、模型失败或存储失败时保留原档案，不用模板或假分布补齐。
- 最多一次模型请求、输出上限6000 token、请求超时不超过180秒，无自动重试；客户端190秒超时。
- 字符预算不是模型token预算，实际上下文兼容性仍取决于配置模型；失败保留旧档案。
- 未新增表、迁移、采集任务或后台模型调用。
