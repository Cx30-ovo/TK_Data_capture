# 标题采用最新已保存账号风格

日期：2026-11-02。本地版本 `opportunity-titles-v0.7.1`，已应用。

## 行为

取消因作品增量、作品移出时间窗口、当前采样SHA改变导致的标题风格“过期”拦截。按当前账号身份读取最近成功保存的风格档案，跨30天和365天等观察窗口，以保存记录ID降序选最新一份，不自动更新档案，不调用模型补档。

风格绑定采用选中档案自己的原始SHA、档案编号、生成时间和分析版本，不能用当前作品集合SHA冒充。不存在档案时仍要求先保存档案或取消风格适配；档案损坏时明确报错，不回退其他账号或旧档案。当前账号身份已更换时，不复用原身份档案。

生成过程中保存新档案仍触发绑定变化检查，拒绝混用，不自动重试。已保存标题与旧幂等记录不重写；旧请求若绑定与当前选择不同可能返回来源变化，须主动发起新请求。先前失败幂等键也不会因本次修复自动重发。
