# 频道分层、地域角色与增量分类 v4

日期：2026-11-10。版本：`editorial-rules-v4.0`。本地源码开发及隔离验收；未推送 GitHub、未部署或访问 Mac mini。真实模型调用和平台采集调用均为 0；未执行迁移、未写正式业务数据库。

## 六项交付

1. 保留已有 `channel` 主频道，新增 `channel_subtopics` 和带原文片段、字段、规则 ID 的细分标签依据。例：民生下的家庭育儿、社区生活、公共服务。仅在已确定的主频道内细分，不用细分词反推或强行确定主频道。明确正文主体优先，话题标签补充，来源、署名、推广标签不参与分类。
2. 新增 `region_locations`，区分事件发生地、关联地点、人物籍贯或身份、机构所在地、报道来源、技术或物产来源、地点歧义。背景地点权重为 0。例：福建记者报道斐济菌草种植，福建是报道者关联背景，斐济是地域线索；来自福建的菌草不是人物籍贯。仅地点词出现时展示为关联地点，不冒称已验证事件发生地。地域标签本身仍是文案规则判断，不是事实核验。
3. 新增结构化 `tag_pending_reasons`：没有有效线索、多个规则冲突、地点角色不明确、题材或地点词典未覆盖。词典未覆盖是规则诊断提示，不声称系统已知道真实题材或真实地点。仅来源出现地域时，不能把来源所在地变成事件地点。
4. 固定 25 条标注测试样本，并提供可重复运行的回归评估工具，分别统计错误分类、漏判、把应待判定内容强行分类、冲突和混淆矩阵。固定样本通过不能外推为真实总体准确率。
5. 启动时读取既有作品，按 ID 游标每批 100 条检查；同版本、作品 ID、文案 SHA 均一致则复用缓存。启动完成后每 15 秒检查增量，新作品及文案变化才重新计算，封面及互动变化复用。每 120 轮进行一次全量分批核对，补偿晚提交、外部导入等时间戳异常。周期取决于每轮处理耗时，通常约 30 分钟。无模型、人工纠正、媒体访问。
6. 内容线索增加默认折叠的分类健康概览，展示当前账号/已加载范围的频道和地域覆盖率、待判定原因、规则版本、缓存更新时间和数量。后台扫描/重算/复用进度明确标为全部账号范围。增加细分标签、待判定原因筛选，与频道、地域、来源、署名及时间筛选取交集。健康概览内部滚动，窄屏保留至少 120px 的作品列表可视区。

## 缓存与数据边界

- 缓存使用 `cache/editorial-rules/<数据库路径摘要>/<规则版本摘要>/` 中的独立 JSON 文件，不新增业务表、列或索引。不同数据库路径及规则版本隔离。文件名是摘要，不直接使用作品 ID 作为路径。
- 缓存记录来源 SHA、规则版本、结果摘要和生成时间，写临时文件后原子替换；内存缓存有 4096 条上限。缓存缺失、损坏或过期时读取即时执行当前规则，不显示过期结果。
- GET 不创建或修复缓存文件，不启动任务、不写数据库；持久缓存只由应用显式启动的后台工作器写入。未启动后台的隔离测试可即时分类，状态明确为缓存未启动。
- 后台更新失败时显示通用错误并重试，GET 仍可按当前规则读取；错误不向界面暴露内部连接信息。
- 原 AI、人工分类记录保留但不读取，不形成纠正经验或训练输入。
- 缓存是可删除派生文件，回退不需要数据库回滚；旧版本缓存保留，当前尚未实现旧目录自动清理。

## 接口兼容

不新增接口。现有 dashboard 和作品分类 GET 在原字段之外增加上述字段。dashboard 增加 `classification_health`；统计分母明确为此次返回的作品，使用 limit 时不能解释成全部作品。主频道和地域字段保持兼容，旧前端可忽略新增字段；旧后端不提供健康字段时，新前端隐藏健康面板。

## 生效、限制与回退

重启本地后端后才会加载 v4 并启动增量缓存。未在本轮自动重启普通采集应用，避免影响在途采集及其他模型模块。构建验证与运行前端切换分开登记；Mac mini 尚未更新。

已按此前构建后切换本地新版的要求，在核对构建阶段零变化后完整备份本地共享前端，再复制资源并最后原子替换 index。最终构建的全部 38 个文件逐文件 SHA 与共享目录匹配；旧哈希资源保留，未删除旧文件。备份目录 `tmp/classification-v4-20261110-01/shared-before-switch`，切换记录 `local-frontend-switch.json`。本次切换没有重启后端，没有请求业务写入口、模型或采集接口。若当前后端仍为旧版本，刷新前端不能代替后端重启。

规则仍受有限词典及文案上下文限制，不承诺所有作品都有细分标签或地域。没有新增索引，增量查询在大数据量下可能仍需要数据库扫描；已限制单批读取和分类工作量，但不是百万级性能验证。历史缓存会占磁盘，暂未自动清理。当前详情与前端筛选基于已加载作品，后台进度是全账号范围，不混淆统计范围。

回退只恢复本轮源码及前端备份，停用新缓存工作器。缓存可在停止工作器后删除或保留，不应删除或回滚业务数据库、历史作品与评论。工作区先前已有的其他变更须保留。
