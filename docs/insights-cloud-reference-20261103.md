# 热点星云参考样式调整

以用户提供的深浅切换 HTML 及三张截图为参考，保留最多 15 条真实采集线索同屏显示，不分页或减少同屏数量。

- 恢复 15 个错位深度位置及循环插值，前景聚焦、后景按深度淡化，保留卡片叠影和轻微旋转。
- 无选中作品时星云占满中栏；点击作品后上下分区；展开阅读后保留缩小淡化的星云并暂停动效；关闭详情恢复探索。
- 悬停卡片或键盘聚焦显示完整标题预览、频道地域与互动快照，可直接阅读详情；点击卡片仍可直接打开详情。
- 标注大小不代表排名，线索依据仍为当前筛选中互动量较高的最多 15 条内容。
- 保留暂停、弹幕、全屏及减少动态效果偏好支持。

验证：TypeScript/Vite 构建、原文展示与缓存回归脚本通过；浏览器确认 15 张卡片、键盘标题预览、标准/展开阅读和详情关闭切换。参考文件作为样式资料使用，未执行其中脚本。
