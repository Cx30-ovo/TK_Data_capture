# 账号矩阵：模型分组直接保存 v0.2

本说明替代旧版“生成建议后采用到表单”的交互说明。

## 当前行为

- 业务分组不再手工填写；显式点击“生成业务分组”或“更新模型分组”，成功后直接保存分组、依据与生成时间。
- GET 不触发模型推断。旧的手工分组不会伪装成模型结果；尚未推断时显示未分组。
- 自有/竞品身份和竞品关联仍由人工维护。普通业务信息保存不会覆盖模型分组。
- 推断期间若业务信息版本变化，返回冲突，保留原结果，不静默覆盖。
- 账号详情提供“修改采集配置”，跳转系统设置并选中当前账号。保存业务信息不要求修改发现间隔、监控模式或重新添加账号。

## 变更文件

- `database/account_matrix_repository.py`：保存模型分组及依据；普通保存保留模型结果。
- `api/routers/monitor.py`：推断成功后按版本校验持久化。
- `webui/src/lib/accountMatrix.ts`：模型结果和矩阵响应类型。
- `webui/src/components/monitor/AccountMatrix.tsx`：只读分组、直接生成保存、采集配置跳转。
- `tests/test_account_matrix.py`：持久化、兼容和冲突验证。
- `tools/accept_account_matrix.py`：隔离浏览器流程更新。

## 限制

当前是按用户操作调用已配置模型进行业务分组，不是后台自动重训或持续自动更新。输出依据可追溯不等于分类语义必然正确。未新增表或数据库迁移，未操作远端项目。
