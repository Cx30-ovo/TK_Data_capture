# 话题监控紧凑折叠界面

日期：2026-11-02。

## 范围

业务源码仅修改 `webui/src/components/monitor/TopicMonitor.tsx`；浏览器验收脚本更新 `tools/accept_topic_monitor.py`。沿用现有主题与原生 details/summary 折叠控件。技能数据库未返回匹配的折叠模式，采用原生键盘语义并实际验收。

- 话题选择改为横向换行标签，移除常驻左侧话题栏。
- 监控配置与时间范围、趋势与话题排行、采集记录与计算口径默认收起。
- 配置摘要保留最近成功时间；趋势摘要保留前三个话题标签。
- 作品改为紧凑排行行，默认仅展示两行文案、作者、发布时间及四项互动计数；详情按需展开查看完整文案、采集时间、增长和命中关键词。
- 核心统计、实时进度、风控和异常提示持续可见；暂停和删除操作保持直接可达。
- 切换话题、翻页或排序后收起作品详情；同一列表轮询保留展开状态。

不修改接口、调度、采集、数据库和模型逻辑，不重启后端，不更改运行监控开关。
