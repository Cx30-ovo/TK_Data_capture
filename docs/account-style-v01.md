# 账号风格档案 v0.1

## 入口与边界

账号矩阵 → 查看与管理 → 查看账号档案 → 账号风格档案。
点击“分析账号风格 / 更新风格分析”才调用已配置的文本模型。
页面读取、每分钟检查输入变化及统计刷新不调用模型，不触发采集。
这是通用模型基于账号样本的推断，不是已训练的专用模型。

## 功能

- 五个维度：内容主题、标题结构、表达习惯、地域定位、可能面向的受众。
- 每个维度附代表作品标题、作品 ID、发布时间、字段与片段 SHA-256。
- 标题沿用 caption-cleaned-title-v2：保留正文案全部句子，去署名、标签和提及；不是只取首句。
- 受众标为推测；不作真实粉丝画像、事实核验或热度预测。
- 新作品或旧材料变化只提示手动更新。失败保留旧分析；历史记录可切换。
- 快照保存到现有 ai_analysis_results，analysis_type=account_style；不新增表或迁移。

## 接口

- GET /api/monitor/accounts/{id}/style-profile?days=30：只读当前输入状态、最近50份快照与模型可用状态。
- POST 同路径，JSON {"days":30}：显式生成；输入不足5篇返回422，忙碌429，模型/依据无效502，存储不可用503，账号身份变化409。
- 每次成功分析插入独立快照；相同输入、模型配置与版本复用最新快照。
- 模型调用最多一次，无自动重试；输出上限3500 token，超时不超过90秒，禁用环境代理和重定向。
- 仅向配置模型发送清理标题和引用元数据；不加载封面、不调用视觉模型。

## 输入及限制

发布时间窗口可选7/30/90/365天；发布时间早于统计时点，首次采集不晚于时点，仅有效作品。
最近最多5000篇中，剔除空标题与超过1500字符的标题，再按时间等距抽样最多40篇。
展示扫描和抽样范围、排除量及扫描截断，不声称随机或全账号覆盖。
输入指纹不包含不断移动的截止秒数；内容、作品集合、窗口或提取版本变化会改变指纹。
超出5000篇的范围不作细粒度变化追踪。
界面显示最近50份历史，更早快照保留在现有表；没有清除或回写原始作品。
未来标题生成可读取同账号、同窗口的已保存档案；本轮未开发标题生成或专用模型训练。
