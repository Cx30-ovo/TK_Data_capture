# 持续监控本地修复记录

日期：2026-11-13。仅修改本地源码和测试，没有部署、重启或访问 Mac mini，没有启动实际采集或调用模型。

## 已完成

### 浏览器连接与恢复

- 初始化细分为 Playwright 启动、受管目标恢复、CDP 连接、采集页获取、页面导航、客户端初始化和登录检查。
- CDP 连接阶段的超时单独归为 browser_connection_timeout，不再直接显示成平台网络请求超时。
- 恢复时，在 Playwright 附着之前使用本机浏览器级 CDP，检查登记目标身份并关闭该受管采集目标；随后沿用现有连接、采集页创建及登录检查。
- 整个恢复操作复用跨进程页签锁，HTTP 和 WebSocket 均绕过环境代理，只允许本机端点，不跟随 HTTP 重定向，不导航页面。
- 仅操作登记 ID 且 URL 属于抖音或空白页的 page 目标。其他页面、登记已失效的目标、已经导航到其他站点的页面均不会关闭。
- 启动预热增加总超时，清理增加超时。恢复仍遵循暂停、冷却、忙碌和退避检查。

此方案解决“必须先完成 Playwright 附着才能重置采集页”的路径依赖；不自动关闭整个 Chrome，也不杀死无法确认归属的进程。如果故障不在登记采集页，恢复仍可能失败，届时会保留退避并报告不可用状态。

相关文件：tools/douyin_cdp_recovery.py、tools/douyin_collection_page.py、api/services/browser_recovery.py、api/services/monitor_service.py、api/main.py。

### 错误诊断

- 失败记录包含诊断 ID、任务种类、阶段、异常类别、堆栈文件名/函数/行号和异常因果链。
- 不记录原始异常消息、URL、请求正文、Cookie、认证信息、局部变量或原始源代码行。
- 前端现有日志入口可以看到带诊断 ID 的提示，后台可用相同 ID 查找对应结构化诊断。
- 评论主分页、子评论分页及初始化失败分别留下阶段信息。
- 写入告警本身失败时，不再让异常处理分支直接终止监控循环。

相关文件：tools/collection_errors.py、api/services/monitor_comments_service.py、api/services/monitor_service.py、api/main.py。

### 评论队列与调度

- 先认领任务，再初始化浏览器；初始化失败也保存错误和下次重试时间。
- 初始化取消时保留游标、释放 running 状态；不把取消记作采集完成。
- 单作品连续失败按 30、60、120、240、360 分钟退避，之后保持最多 360 分钟；不删除待采任务，不限制最终可采评论总数。
- 快照刷新不能绕过评论错误退避；成功页面恢复正常调度。
- 延续本地已有的“发现/快照优先、评论排队分片”改动；没有提高请求并发或缩短平台请求间隔。
- 新计数放在既有 payload JSON 内，没有新增表、列、索引或迁移。

相关文件：api/services/monitor_service.py、api/services/monitor_comments_service.py、database/monitor_comments_repository.py。

### 业务健康与重启状态

- 原 /api/health 继续表示 API 存活。
- 新增只读 GET /api/monitor/readiness；可用时返回 200，其余状态返回 503。状态包括 starting、ready、degraded、recovering、cooldown、paused、login_required、stalled 和 stopped。
- /api/monitor/execution 新增 business_health 字段，保留原字段。
- 业务健康从内存读取，GET 不写状态文件、不写库、不触发平台请求。
- 不用“发现了新作品”作为成功检查的必要条件；没有新作品的成功发现也记为成功。
- 发现成功不会直接清除评论任务种类的故障，分别记录最近成功和未解除的失败。
- 状态文件与源数据库放在同一目录，文件名为 monitor-runtime-state.json；原子替换保存暂停、冷却截止、风控次数、发现退避与浏览器恢复状态。GET 不保存文件。
- 状态损坏或写入失败时暂停监控，避免静默丢掉冷却和暂停设置。启动预热不会绕过已恢复的暂停、冷却或恢复等待。

readiness 是业务状态，不能拿它代替进程存活探针直接触发无限重启；用户暂停、登录失效和平台冷却不会靠重启解决。

相关文件：api/routers/monitor.py、api/services/monitor_runtime_state.py、api/services/monitor_service.py、api/main.py、.gitignore。
