# 洞察界面空间与调度显示优化

- 顶部导航60px、账号栏34px、状态栏30px，总高度从158px缩减到124px；手机保留原有双行导航适配。
- 频道/地域改为有可见标签的紧凑下拉，保留全部选项；时间范围与搜索紧凑排列，支持收起/展开。摘要持续展示当前条件，可一键重置。
- 筛选、日期、关键词与账号变化后作品列表回到首条，重置加载条数；卡片上下间距适度收紧。
- 快照状态依据服务端当前时间推进，每10秒更新：未来显示分钟/小时倒计时，到期显示待执行或已延迟，暂停/恢复/冷却/执行状态分别展示。轮询失败或数据超过90秒未刷新时显示状态待刷新。保留计划时间、阶段及作品标题的悬停说明。
- 17项快照状态边界检查及前端构建通过。浏览器验证了组合筛选、重置、折叠和滚动回顶；验证1920×900、1440×900与390×844布局及深浅主题。
- 1920×900实测：筛选区约129px，作品列表约474px，收起后约603px。实际调度显示等待浏览器恢复，不再将过去时间当作下一次执行时间。
