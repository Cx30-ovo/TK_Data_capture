# 标题预算与质量缺口修复 v0.3

日期：2026-10-29。已应用本地新版并重启后端，原监控、自动发现和自动分析配置已恢复。

## 结果

1. 标题每日预算由 4 次扩大到 20 次；单次仍最多 3000 输出 token，单次请求不自动重试。已有预约用量及历史记录保留，不清零、不删除。每日最多预留 60000 输出 token，实际输出受配置限制。总存储仍为 100 条历史请求，触达时独立显示存储上限，避免与每日预算混淆。
2. 从已有发布文案生成带来源、偏移及绑定 ID 的信息片段。模型必须选择标题主要动作或结论对应的 `primary_fact_id`，服务端校验真实片段及角度引用关系；同一核心事实片段只保留一条，跨角度标签同样去重。来源归因和孤立日期片段不作为新的事实候选。
3. 勾选账号风格时，模型结构要求每条至少一项风格采用说明；提示词要求先选可用特征再写标题。服务端独立过滤缺少采用说明、特征 ID 不存在、标题片段不可定位的结果，不能静默返回普通标题。有效档案没有可用风格特征时，在模型请求前拒绝。
4. 界面同步展示每日 20 次限制、必需的风格采用要求、核心事实依据、同事实过滤和缺失风格过滤原因；全部被过滤时明确说明没有用普通标题替代。

## 限制及使用

本轮模型调用均为模拟，真实模型请求为 0。已恢复的原有自动任务继续沿用原配置，不能将本轮测试零调用理解为后台长期不调用模型。

事实片段是原文分句，不等于独立核验过的语义事实。相同片段可确定去重，但不同片段间的同义事实仍可能漏检；模型可能选错片段，原文片段关系校验不能完整证明标题核心语义。因此不宣称语义去重完整或准确率达标。

风格采用要求已由可选改为必需，但特征及标题片段可定位不等于风格符合度已独立证实。模型未满足要求时会少返回或返回空数组，不使用模板、不伪造采用说明。

刷新页面后，新的生成请求使用新规则及 20 次预算。旧结果不会自动重写；同一幂等键仍返回原结果。已有失败请求不会自动重发，可刷新后由用户主动发起新请求，消耗当日剩余预算。

下一步：选择一条近期真实线索，勾选账号风格生成一次，核对核心事实、关键限定和具体风格说明。若仍有跨片段语义重复，保留该真实样本用于下一轮针对性验证，不通过自动多次重试消耗预算。

回退：恢复本轮有范围的源码及完整构建备份后安全重启；不回滚数据、不修改历史请求。未提交、推送、远程部署或访问 Mac mini。
