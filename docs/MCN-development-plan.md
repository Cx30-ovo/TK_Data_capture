# MCN 内容决策支持平台：本地开发计划

日期：2026-10-22。基线：GitHub main `7fe2b7a`。本地开发，不同步 Mac mini。

## 产品范围

为 MCN 与媒体编辑提供热点发现、选题策划、标题选择、发布关联和复盘。

1. 账号矩阵：多账号管理，自有/竞品角色、分组、人工定位及随作品更新的数据观察档案。
2. 同事件对比：发布先后、角度、标题/封面、同生命周期表现、我方未覆盖内容。主题相似不能直接当作同一事件；仅标题材料不得宣称全文事实覆盖。
3. 热点雷达：事件摘要、时间线、萌芽/上升/当红/持续发酵/退潮观察状态；预测与观察分开。
4. 标题策划：基于已核实证据和指定账号风格，提供 3—5 个候选及每个标题的独立引用；材料不足不得凑数。
5. 历史日历：区分作品发布日期、事件发生日期、周年/计划节点；价值排序给出依据和待核实项。
6. 发布复盘：编辑选择、修改、拒绝理由，关联实际作品和同生命周期结果，形成训练反馈。

专用模型为正式目标：内容分析/标题模型与热点预测分别训练、评估。模型地址、基础模型、GPU、数据授权、预算尚未确定；本轮不启动训练、不调用模型，不用统计规则冒充训练模型。

## 预测验收约定

- 已监控账号覆盖范围内，预测未来 24 小时是否达到热点门槛。
- 每日前 5 个事件，Precision@5 ≥70%；连续 30 天前瞻验证，目标 150 个预测记录。
- 150 个有效推荐记录至少 105 个命中，仅表示样本命中率达标，同时报告置信区间。
- 同事件不重复凑数，已达热点门槛不能算提前预测；不足 5 个如实登记及报告覆盖率，不能只挑容易样本。
- 同报召回率、误报、提前量、样本数和简单热度排序基线；测试前冻结输入、标签和规则。
- 按时间划分训练/验证/测试，转载及同事件不得泄漏；事后补采不能作为预测时可见数据。
- 热点门槛、事件归并规则、独立来源标准和数据缺失处理尚需定义，70% 目前是目标，不是已实现能力。

## 本轮接口与页面

`GET /api/monitor/accounts/{account_id}/profile?days=30`

- days 为 1—365，页面提供 7/30/90/365 天；发布时间 start ≤ publish < end，first_seen ≤ end。
- `account-title-profile-v0.1`；包含账号、窗口、样本计数、长度分布、标题表达标记、原始话题标签、标题证据、观测覆盖、限制和输入 SHA-256。
- 字符按去首尾空白后的 Unicode 码点计数，包含标签和标点，不代表中文分词数。
- 标签每篇去重，按篇数降序、标签文本稳定并列排序。问句/感叹仅检测标点，不判断语义或情绪。
- 最多使用最新 5,000 篇，返回窗口有效总数、实际样本数、截断标记。样本统计不冒充全量统计。
- 只读 SQLite 一致性事务，不自动建表、不采集、不调用模型、不保存统计结果。
- 观测 captured_at 与 created_at 均 ≤ end，实际年龄须等于 capture − publish 且非负。阶段覆盖按现有 1h±30m、6h±2h、24h±6h、72h±12h、7d±24h 窗口计数；累计观测不冒充阶段观测。不输出互动排名或因果结论。
- 404 账号不存在；422 参数不合法；503 数据库未初始化或结构不可用。不自动创建或回退。
- 入口：账号配置区 → 选择账号 → “查看账号档案”，原位展开。首开才请求，不串联发现/快照；关闭重开会重新读取本地数据，切换窗口/“更新统计”也会读取，无后台轮询或持久缓存。
- 新采集作品在下次读取时计入，无新增后台任务；未实现模型风格分析及历史档案版本。
- 错误时隐藏旧结果，显示不可用；缺标题/观测及空窗口如实展示。

## 本轮人工浏览器验收清单（待执行）

1. 选择不同账号，档案身份和统计不混用；新建账号表单不显示旧档案。
2. 未展开无档案请求，首开一次；折叠/重开、切换窗口、更新统计行为符合说明。
3. 无作品、有作品但无标题、无话题标签、无观测均有明确空态；0 不显示为缺失。
4. 标题长度按 Unicode 码点计数，标签按作品去重；证据定位到作品 ID 和 title。
5. 截断时展示 5,000 篇上限及真实总数，不声称全量档案。
6. 404/503/网络失败显示错误，不触发采集或模型。
7. 1440/812/375 宽度，深浅色，长标题/标签/指纹不溢出。
8. 键盘 Tab、Enter/Space 展开，表单有标签，加载/错误状态可被辅助技术读取。
9. 原账号添加/编辑、切换未保存提示、发现/暂停操作行为回归。

本轮不启动普通应用，防止自动采集、维护和模型任务；浏览器验收尚未执行，不标记通过。前端独立构建，保留 api/webui 原状态。
