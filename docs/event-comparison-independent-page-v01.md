# 同事件竞品对比独立页面

日期：2026-10-26（Asia/Shanghai）。已验收并切换本地前端。

## 页面与边界

左侧业务工作台新增“同事件竞品对比”，独立地址查询参数 `?tab=event-comparison`；支持直接打开、刷新、浏览器前进后退。账号矩阵不再嵌入或加载对比模块，继续管理账号身份、竞品关系、业务分组和账号档案。

独立页面直接展开作品选择，复用既有候选发现、固定批次/历史、人工判断、漏检补录、发布时间、缓存封面、切入角度与同期观测功能；不需要先点“开始对比”。顶部“管理账号关系”跳回账号矩阵。独立页只列出已关联有效竞品的自有账号，避免默认账号未关联时无法切换到其他可对比账号。

页面复用账号矩阵只读接口和同一查询缓存；未配置有效账号关系时显示引导，不自动配置；读取失败隐藏旧结果，可显式重读。新增导航中英文翻译，业务组件已有中文文案沿用。视觉沿用现有主题与组件，ui-ux-pro-max的键盘导航建议用于入口与返回路径核对，没有添加远程资源。

离开页签时，未保存的选择/勾选/编辑等内存状态仍按既有页签卸载行为重置；已保存判断、批次与历史不受影响。没有承诺跨页保留未保存内容。
