# 分类规则第二轮优化

日期：2026-11-10。版本：`editorial-rules-v3.3`。

## 本轮结果

继续采用自动规则、发布文案和话题标签，不使用 AI 复核或人工纠错。仅修改 `api/services/post_editorial_tags.py` 与 `tests/test_post_editorial_tags.py`，不修改接口、前端或数据库结构。

新增规则覆盖选举、全会、宣判、校庆、特教、歌剧、音乐会、社区服务、天气、桥梁合龙等明确事件。规则仍以原文片段为依据，不用人物名、媒体栏目名、情绪词或账号所在地直接推断题材或地点。

复合标签先识别具体对象：`AI诈骗` 归法治，`AI短片` 归文娱，`两岸美食` 归文旅，`国防教育` 归时政，`医学模拟教育` 归教育，`体育经济` 归经济。不同标签支持多个方向且难以区分时保留待判定，不按标签数量强行选择。

上下文处理补充了：党代表谈医疗／技术优先按具体内容判断；交警护送中目的地医院不独立建立健康题材；探店骗局优先法治；台风预警优先应急；反诈骗算法研发保留技术题材，区别于 AI 诈骗事件。

地域词典补充有限国家、城市和厦门地点。球队或选手的地名不是比赛地点；“中国梦”“中国歌剧节”等名称不是事件地点；境外报道中的“全国哀悼”等表述不直接证明发生在国内。未依据新闻名称或未经验证的事件记忆填补地点。
