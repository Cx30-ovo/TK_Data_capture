# 自动竞品分析 v0.1

日期：2026-10-26。已完成本地开发、隔离验收与本地运行版本切换。

## 本批交付

独立“同事件竞品对比”页顶部新增“自动竞品分析”。选择一个自有账号、一个已关联竞品、近 3/7/14/30 天及本批最多 1/3/5/10 对，一次启动后自动逐对处理，无须逐篇选择或先人工勾选同事件。原人工检索、配对反馈、漏检补录、封面缓存对比、同期观测仍保留。

处理链：冻结字面候选批次 → 全批材料和上下文预检 → 原子预留预算并持久化任务 → 逐对模型判定关系与分析 → 服务端解析精确片段 ID、绑定证据 → 再校验来源 → 保存结果。关系区分同一事件、仅同主题、后续进展、不同事件、材料不足；只有同一事件允许列出差异线索。非同事件不展示同事件同期表现对比。

每项依据包含来源作品 ID、字段、精确片段、材料 SHA、片段 SHA。差异区分新增核心事实线索、切入角度、背景、表达。全部标注标题级推断、未经人工核验，不认定全文事实或账号整体未覆盖。不会将模型判断自动写成人工反馈或训练标签。现阶段模型输入仅为清理后发布文案，自动结果没有新增视觉推断、封面下载或外部资源加载。

进度展示总召回、本批计划、未安排、已处理和请求数；已处理包含成功与失败，逐条区分失败。单条模型失败不伪造结论，继续其他条目且不自动重试；来源/身份/配置失效则停止后续条目。停止允许当前在途请求完成，保留其可校验结果。历史任务可重新打开，GET 校验当前材料，不重新调用模型。再次点击同一个历史任务也会重新读取校验状态；这是浏览器验收中发现并修复的缓存展示缺陷。

## 接口与存储

新增接口：

| 方法 | 路径 | 行为 |
|---|---|---|
| POST | `/api/monitor/event-comparison/automatic-runs` | 启动显式批次；参数 owned_account_id、competitor_account_id、days、max_pairs、save_key |
| GET | 同上 | 账号对、page 分页读取任务目录，每页 5 条 |
| GET | `/api/monitor/event-comparison/automatic-runs/{job_id}` | 读取完整任务与最多 10 对结果，逐对复核材料，不写入或调用模型 |
| POST | `/api/monitor/event-comparison/automatic-runs/{job_id}/stop` | 停止后续分析；关系变化后仍允许按任务 ID 取消 |

原接口不改变。普通导航、刷新、打开历史仅 GET，不启动推断。模型关闭/状态不可用时入口禁用，服务端同样拒绝新分析；模型关闭不影响已经存在任务的读取与同键重放读取。

任务存入采集库旁独立 `automatic_comparisons.db` 的 `analysis_jobs`。只在明确 POST 启动时首次创建，不接入采集库自动建表；采集库在该模块内始终只读，未执行采集库迁移。候选快照复用独立 `event_candidate_runs.db`。历史读取缺文件返回空目录或明确不存在，不自动建表或修复损坏记录。

幂等：同 save_key、同请求返回原任务；不同请求冲突 409，不重新推断。任务绑定冻结批次/输入 SHA、派生版本和模型配置摘要，配置摘要包含模型、提供者、地址摘要、上下文/输出预算和提示词版本，不保存地址、认证内容。显式新 save_key 是新任务，会消耗预算；目前不跨新任务复用已成功配对结果。

上限：每批最多 10 对、每对最多 1 请求；该模块每日最多预留 50 请求（本地日期），先原子预留，失败/停止不退回预留。不是其他 AI 模块的全局预算。输出每请求最多 2600 token 且不超过模型配置；输入采用保守 UTF-8 字节上界加 schema/提示词/输出预算预检，不下载 tokenizer、不静默截断或回退。元数据新建时检查 500 任务及 128 MiB 阈值，单条任务最多 2 MiB，不删除旧任务。128 MiB 是新增任务准入阈值，不能当作 SQLite 文件绝不增长的物理上限；已有任务结果更新和 SQLite 页开销仍可能使文件继续增长。

任务运行仅支持当前单后端 worker 模式。服务重启不自动重放模型请求；进程异常退出遗留的 active 任务在详情显示中断，需显式停止旧任务再新建。服务正常取消能登记 interrupted；硬中止不保证完成登记，依据进程内任务注册判别。多 worker/多实例调度、自动恢复执行和集中预算尚未实现。

本地后端经在途任务与调度核对，安全暂停监控、核对确属本项目的父子进程后重启，注册新路由。切换后监控恢复原未暂停状态，调度仍关闭。在线仅 GET 验证健康、新接口注册、已有账号对任务空目录和 38 个已应用文件的 HTTP 内容 SHA；没有代启动真实分析、代写真实反馈或改变采集频率/冷却。结果在 `live-readonly-check.json`。一次对根路径 daily.css 的探测返回 404，核对后确认既有日报实际引用 `/static/daily.css`，该实际路由正常，未为此修改路由。

## 范围与下一步

这是显式发起后的自动批量配对分析，尚不是无人值守、全量事件自动归并或自动选题生产。候选仍是现有字面召回，默认 72 小时配对范围；每批只取当前顺序前 N 对，未安排数量明确展示。目前不支持自动接续剩余候选、跨批次成功结果去重，也不能识别所有“竞品有而自有完全没有作品”的事件。

真实模型质量尚未以本批实际业务样本验收；没有训练专用模型，也没有取得热点预测 70% 命中率证据。模型输出引用可定位，不意味着事实或推理必然正确。

下一步建议先在本地页面选择 1 对真实候选，显式启动并核对关系与证据；通过后再做跨批次去重/增量队列、竞品独有事件与覆盖缺口、定时受预算控制的自动分析、人工反馈沉淀，随后进入训练与前瞻评测。真实模型验收应单独登记输入、模型版本、请求数、人工判定及失败案例，不用本轮模拟测试代替。
