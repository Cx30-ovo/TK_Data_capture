# 同事件竞品综合分析 v0.2

本轮将清理后发布文案、匹配当前封面的缓存识别、有效阶段快照一并送入现有自动分析请求。模型关系判定与文案引用规则保留，新增封面内容、同期互动、快照变化三个独立结果区。新任务使用 `automatic-competitor-analysis-v0.2`；旧记录保留，不自动重算。

## 材料与边界

- 封面：只读 `cover_vision_labels`，按作品与当前封面 URL 哈希精确绑定，并限制缓存创建/更新时间不晚于本次材料截止时间。使用有效 OCR、主体和视觉标签，不在浏览器加载远程图片，不临时下载图片或调用视觉模型。封面识别是既有模型观察，不是人工核验，也不等于本次直接看图。
- 互动：采用现有 1h/6h/24h/72h/7d 阶段选取与实际年龄容差规则。四项原始累计计数保留 0，缺失不补 0。互动差异引用必须来自双方、同阶段、同指标且可比的快照。
- 快照变化：服务端按同一作品相邻有效阶段计算计数差，保留起止值、采集时间、经过秒数。比较双方变化时，阶段区间和指标必须一致，两端均需满足可比条件；计数回落不支持增长结论。不是曝光归一化表现或预测。
- 非同事件不生成三类综合对照；材料不足明确显示未分析。模型提示禁止推断封面/标题造成互动变化，服务端校验证据身份、材料类别、阶段和数值可用性。自然语言解释仍是模型推断，不能视为传播因果证明。

## 接口、绑定及存储

没有新增端点、请求字段、表、列或迁移。现有任务 JSON 增加 `material_input`（材料截止时间、版本、摘要哈希、完整证据目录及限制），分析增加 `cover_analysis`、`interaction_analysis`、`snapshot_analysis`。每个 finding 引用服务端证据 ID，服务端解析为材料值、字段、作品、时间及哈希，拒绝不存在、错类、跨阶段和单方证据。

材料在调用前组装、调用后按同一截止时间复核。源材料发生修改时不保存本条结论；GET 只读核对原截止时间的材料，发现变化则标记 `analysis_material_current=false`，保留旧记录。后续正常新增观测不重写旧输入。旧版任务不被升级或覆盖，旧幂等请求仍返回原任务。

每对仍最多一次模型请求，每批最多 10 对、每日最多 50 次预留，不自动重试。综合输出上限由 2,600 调整为最多 4,000 token，且不超过配置上限；调用前按完整输入、输出上限及结构预算检查上下文，超限明确拒绝，不静默删除材料。
