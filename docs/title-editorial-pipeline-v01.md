# 标题事实提炼、角度规划与复核

日期：2026-10-29。已应用本地新版，生成结果版本 `opportunity-titles-v0.4`，流程版本 `title-editorial-pipeline-v0.1`。

## 实现

单次结构化模型请求按顺序返回可审计的结果，不索取或存储模型思维过程：

1. 独立事实：主体、动作、结果、事实摘要、原文片段 ID、必须保留的限定词。允许把接收方、返还方、文物数量及名称对应的多个原文片段归入同一次交接事实。
2. 角度计划：引用独立事实，说明角度、具体信息重点和取舍理由。同一主事实至多一个计划，材料不足不补背景或服务解读。
3. 标题与复核：每条标题关联计划，模型逐条记录保留或排除、问题和重复对象；服务端再独立验证事实/计划/标题关联、限定词、风格依据、原文引用、重复和数字等边界。

同一独立事实即使对应不同原文片段，也不能靠跨片段换写保留多个标题。模型自查建议保留不能绕过服务端过滤。模型自查发现问题时过滤；阶段引用、事实 ID 或复核记录不完整时拒绝保存，不自动重试或生成模板。

模型必需限定词必须能在绑定来源中定位；服务端补充检查片段中的“第二次”等次数及“疑似、涉嫌、尚未、并未、可能”等窄范围限定。该检查不穷尽所有限定。

## 界面

默认仅显示“事实 N 项 → 角度 N 项 → 标题 N 条”。原位展开显示独立事实、事实原文片段、角度理由及模型逐条自查。每条标题显示关联事实和计划，继续展示具体账号风格采用依据及服务端过滤原因。

## 边界与下一步

三个阶段在一次结构化请求内完成，没有三个串行模型调用；后续阶段以结果引用前序阶段，服务端验证关联，不能据此证明模型内部执行顺序。不是独立模型二次审稿，也不宣称事实核验完成。

语义事实归并由模型完成。服务端可阻止相同片段重复归入不同事实、近似主体动作结果重复和同一独立事实的多个标题，但模型仍可能错误拆分或合并事实，无法保证穷尽跨句同义表达。绑定片段不证明事实摘要语义完整。

每日仍最多 20 次，单次输出仍最多 3000 token，不自动重试。阶段结构增加输出开销，复杂材料可能达到输出预算；遇到截断拒绝结果，不静默省略阶段。旧幂等结果保留原样，不重算、不批量更新。无新增表或迁移，未修改采集、分组或匹配算法。

本轮真实模型调用为 0，所有标题推断测试为模拟；不能据测试宣称真实模型质量已提升。原有自动任务按原配置恢复，与本轮测试零调用的范围区分。
