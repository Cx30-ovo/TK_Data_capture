# 作品频道和地域标签

- 所有 dashboard 作品按标题、正文即时生成标签，兼容历史及新增作品，无需回填数据库。
- 本地：厦门市及其辖区。本省：福建省级内容，以及福建省内除厦门外的城市。国内：其他国内地区（含港澳台）。国际：境外内容。
- 标题优先于补充正文，明确的事件地点优先于一般地名。忽略发布账号、来源署名及推广话题标签。没有明确地名的内容显示“待判定”。
- 频道采用关键词加权规则；未命中频道显示“综合”。“推荐”是全部频道入口，不代表算法推荐标签。
- 已改为规则初筛＋AI复核：频道无命中/得分接近、关键词歧义、地域缺失/多地冲突进入后台队列，其余作品直接使用规则。
- AI每批最多8篇，串行复核，90秒超时；同一作品去重。面板先返回初筛值，不等待模型，30秒刷新后展示复核结果。
- 模型仅能修改存在歧义的字段。ID、标签枚举、置信度和原文引文均校验；置信度低于0.8、没有原文证据或地域证据缺少对应地名时，频道保留综合/地域保留待判定。拒绝通过方言、活动名称或发布机构猜地点。
- SQLite表 post_editorial_labels 持久化结果；缓存键含原始内容、作品ID、模型/服务商/地址和规则提示词版本。内容或模型变更后重新复核。信息不足的结果也缓存，避免重复花费。AI故障保留规则值并显示待重试，冷却5分钟后后续请求重试。
- 页面显示AI复核中、AI已复核、需核实或AI待重试；自动结论不是已核验事实。
- 首页支持频道、地域、日期、时间范围与关键词组合筛选；作品列表、阅读详情、星云和作品数据表展示标签。平台热榜未采集作品不冒充已归类作品。

验证：36项分类与服务测试、前端TypeScript与Vite构建通过；已使用配置模型验证跨地域和信息不足示例，并核对真实作品纠正动物居民为环境生态。

## 第二轮优化

- 版本 editorial-hybrid-v3：医学、生态和车管所等完整语境归类；排除医学生中的学生、经济舱中的经济、动物居民中的居民，减少误判及冗余AI复核。
- AI输出逐作品校验，有效结果立即保存；缺失、重复或无效条目仅对该作品设置重试，不阻断其他有效结果、不触发全局服务故障冷却。未知ID忽略。
- 空正文和仅作品ID跳过AI，显示内容不足。详情新增可直接阅读的频道/地域证据、复核理由和模型自评说明，适配两种主题。
- 验证：43项测试及前端构建通过；实际接口核对生态新闻通过规则直接归为环境生态、本地；浏览器确认AI复核依据可在详情中直接阅读。
