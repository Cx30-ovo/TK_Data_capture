## 变更与行为

- `api/services/post_editorial_tags.py`：修正正文中 `#话题词` 清理，保留其文字和后续句子，单独清理尾部标签；保留原文偏移供证据引用。补进博会、投洽会、围棋赛事、救援、家庭日常等规则，以及有限的地名别名。
- 同文件增加独立标签解析：明确题材标签可补足正文缺失信息；频道名标签权重 2，具体题材权重 4。同频道仅取一个最高标签权重，重复标签和近义标签不能无限累加。正文明确线索优先；多方向接近时待判定。
- 地域标签只识别完整地名、行政区组合和少数明确范围标签。正文无地点时可使用地域标签；正文已有地域时，标签不能改写正文判定，也不能消解正文中真实的多地域冲突。冲突标签保留原文并显示未采纳。
- 账号宣传、媒体原创、上热门等标签过滤。来源署名中的 `#词` 不作为作品标签。`#厦门广电看金鸡` 不等同于厦门地点证明；`#中国国际短视频大赛` 不等同于境外事件。
- `webui/src/components/monitor/PostEditorialTags.tsx`：依据区分文案与话题标签，展示标签命中、权重及冲突原因，说明标签不等于事实核验。
- `tests/test_post_editorial_tags.py`：增加覆盖、误判防护、标签独立补充、冲突、层级地点、原文依据和重复标签限权重验证。原先“标签不能独立判定”的测试按本次新授权调整，未跳过失败测试。

没有新增接口或改变已有字段形状；规则证据继续使用原 `rule_id / field / snippet / candidate / score`。规则版本升级用于区分结果。原始文案、旧 AI／人工记录、表结构均不修改，不启用 AI 或人工纠正。

## 生效与限制

前端已本地应用，后端未自动重启。重启本地后端并刷新后，确认标签依据中的规则版本为 `editorial-rules-v3.2`，新旧作品读取时使用新规则，无数据迁移。

规则与标签均不保证理解作品实际内容。错误标签、暗示性标题、纯人物名、地点歧义和跨频道事件仍可能误判或待判定；没有依据时不强行归类。真实准确率需独立标准答案评估，不能由待判定数量下降推导。
