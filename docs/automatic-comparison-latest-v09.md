# 默认读取最新已对比记录

前端 `AutomaticComparison.tsx` 在进入页面和切换账号组合时，使用已有只读分页接口，按服务端倒序选择最新 completed/stopped 且已处理数大于 0 的批次。第一页没有合适记录时继续分页；未完成、失败任务与零候选批次不作为默认记录。读取材料仍由已有 GET 校验来源，不重新分析。所有配对默认收起。

手动选历史、启动新任务或修改检索窗口/本批对数时停止自动选择，避免异步结果覆盖用户操作。模型关闭仍可读取存档。没有记录保持空状态，读取失败明确提示；批次原始窗口、账号、创建时间仍由保存记录展示，不伪装成当前条件下的新分析。
