# 同事件竞品对比视觉优化

2026-10-26，本地页面已应用。

优化集中在 `webui/src/components/monitor/AutomaticComparison.tsx`，没有改变接口、缓存、模型请求或数据结构。

- 顶部参数区独立成控制面板，账号、窗口、本批数量和启动操作保持同一视觉层级。
- 无结果时展示三步流程：发现候选、模型对照、查看依据，避免空白页面。
- 批次结果增加召回、本批安排、成功数、模型请求四项统计卡片，并显示进度和绑定信息。
- 增加结果筛选：全部、同一事件、其他关系、执行/来源状态；筛选为前端展示操作，不产生请求。
- 单条结果按“模型结论 → 双方文案 → 发布时间 → 差异与依据”排列。
- 自有与竞品使用左右对照卡片，统一账号标签、标题和发布时间层级。
- 原文片段、材料 SHA 和片段 SHA 默认收进可展开证据层，减少长文本噪声。
- 同期互动改为观测阶段选择器和自有/竞品表格，明确 0 与缺失的区别，不用长段落堆叠。
- 使用现有主题语义色和 Lucide 图标，支持键盘焦点、深浅色和窄屏换行。
