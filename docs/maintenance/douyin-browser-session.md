# 抖音浏览器会话与快照修复

## 适用问题

同一网络下，已登录浏览器能正常打开作品，但独立程序请求返回
`Blocked by ArgusSecurityPlugin Uifid Not Found` 或 `Sign Invalid`。
这说明浏览器能访问页面，并不代表复制 Cookie 后的独立请求具有相同的会话状态。

## 请求路径

- 直连且有浏览器上下文时，作品详情和账号作品列表复用专用 Chrome 的后台采集页签，与用户页签共享登录，不为每个请求新建标签，也不跳转用户正在浏览的页签。
- 读取网站正常加载页面产生的接口响应；不自行伪造或重放平台的校验标识。
- 详情按作品 ID 匹配，列表按账号 ID、请求游标匹配；允许正式 `douyin.com` 子域，但拒绝其他域名。
- 账号列表通过页面正常滚动获取后续页；每个客户端的页面操作间隔至少 5 秒。
- 平台拒绝后直接返回错误，不再额外发一次 HTTP 回退请求。
- 结束任务时仅移除响应监听和分页状态，不关闭后台采集页签；不存在时在同一 Chrome 上下文创建带专用标记的后台页签，不占用 WebUI 或其他页面。
- 服务启动是例外：先准备用户可见的专用抖音登录页签，再启动自动监控。已有抖音页签直接复用；首次 Chrome 的 `chrome://newtab/` 空页面可用于打开抖音；只有 WebUI 或其他网站时，在同一个专用 Chrome 中补开一页。启动时将登录页签置前，实际采集复用独立后台页签。
- 普通账号爬虫先完成列表翻页，再依次跳转作品详情，避免同一页签的详情导航打断分页。
- CDP 管理器释放连接时保留 Chrome 的共享上下文；只有该管理器新建的上下文才会关闭。普通退出不结束共享 Chrome，显式退出进程也只处理本管理器持有的浏览器进程。
- 使用代理时保留原 HTTP 请求路径，浏览器路径不替代代理传输。

客户端同时在请求前从真实浏览器更新 Cookie 和会话标识，避免端点复制的请求头继续使用登录前的数据；浏览器版本取自实际 User-Agent。

## 风控退避与数据完整性

将部署端原有的退避保护一并纳入版本管理：识别风控响应后暂停后台发现和快照请求，首次 30 分钟，连续失败按倍数延长，最多 6 小时。
快照批次遇到风控立即停止后续请求；成功发现作品或完成快照后重置退避。
退避状态目前保存在进程内，重启会重置，不代表平台风控已经解除。

快照必须返回对应作品 ID，并包含点赞、收藏、评论、分享四项指标。缺字段属于失败，不能当成零写入；真实零值可以正常入库。
补采使用实际采集时间，不推算或伪造封控期间历史时刻的指标。

## 验证与维护

### 全局页签锁与采集控制

- `browser_data/douyin-tab.lock` 使用操作系统文件锁，在同一项目的 API 监控、普通抖音爬虫进程之间互斥。整个扫描、详情采集和资源清理期间持有锁；嵌套请求复用租约。进程退出后系统释放锁，不删除锁文件。
- 等待锁最多 30 秒，超时显示“抖音页签忙碌”，不是风控；等待期间可以安全停止。用户手动切换或关闭页签不能被程序锁住，检测到后提示恢复页签，避免继续使用无效分页状态。
- 账号监控和任务中心显示本轮账号、阶段、扫描页数/作品数、已保存数量、快照处理数和耗时。发现总量未知，不展示虚构百分比；快照按本批任务数显示真实进度。
- “安全停止”暂停自动发现与快照，等当前请求和数据库保存完成：发现保存已扫描作品，快照保存当前作品，后续任务保持待执行。“恢复监控”不绕过风控冷却。暂停和进度保存在当前服务进程，重启会重置；这是监控控制，不替代普通爬虫原有的停止按钮。
- 发现中途出错仍保存已取得的有效作品，并返回部分成功；未完整扫描不更新账号的发现完成时间。风控中止整批；登录失效暂停监控等待人工处理；页签异常/连接中断进入自动恢复；网络超时停止当前批次，连续三次超时进入自动恢复；已删除作品终止其任务；缺字段不按零写入。
- `GET /api/monitor/execution` 获取状态；`POST /api/monitor/execution/stop?run_id=...` 安全停止；`POST /api/monitor/execution/resume` 恢复监控。过期 run_id 返回 409，不影响新任务。已知采集失败以 `status/error_code/reason/action` 返回，不再显示未解释的 500。

新增离线回归：`tests/test_monitor_control.py`，包含真实子进程文件锁、等待停止、资源释放、部分保存和控制 API；不访问抖音或生产数据库。

### 监控账号管理

- 账号 ID 在创建时校验并固定，支持正式抖音主页链接或完整 ID；拒绝搜索页、作品链接、其他网站以及 ID 与主页不一致的输入。重复新增返回 409，不覆盖原配置。
- 配置修改与发现状态分开更新。发现完成只更新最近成功时间；每轮结果与结束时间按账号保存，重启后仍可查看。界面刷新保留未保存草稿；切换、新增前可选择保存、放弃或继续编辑，离开网页时提示未保存修改。
- 正常监控：发现新作品并执行快照；仅停止发现：已有快照继续执行；暂停全部采集：停止发现及快照，当前请求完成后生效。暂停不修改任务计划时间，恢复后超出原执行窗口的任务标记为 missed，不能补成历史快照。
- 删除账号配置会将其 pending 快照终止为 skipped，保留作品、已采快照和历史任务；正在请求的快照可以完成并保存。它不会删除历史数据库数据。
- 账号列表支持搜索、状态筛选、异常优先排序和批量发现间隔；批量更新在一个事务内执行，任何账号不存在时整批失败，不修改其他账号。
- 列表显示今日首次发现作品数、到期 pending 任务、异常任务（failed + missed）、最近成功时间和下次计划时间。共享浏览器风控、恢复和全局暂停单独提示；页面中的快照按钮明确作用于全部账号。
- 两个账号面板固定为相同高度，详细配置和记录滚动查看，最近结果使用侧边抽屉。数据库启动时仅追加三列，旧账号原启用状态保留，默认不暂停已有快照。
- 离线回归：`tests/test_monitor_account_management.py`，覆盖旧结构迁移、身份校验、批量原子性、暂停/恢复、结果保存和移除账号。

### Chrome 自恢复

- 默认开启，配置位置为 `config/base_config.py`：`ENABLE_BROWSER_AUTO_RECOVERY = True`，`BROWSER_RECOVERY_TIMEOUT_SECONDS = 90`。这是 Python 配置，不是 `.env` 配置；修改后重启后端生效。
- 后台监控空闲时每 60 秒检查已记录的 Chrome 调试端口。连接中断、采集页切换/关闭会安排恢复；连续三次网络超时会重建采集页。一次有效采集会清零连续超时计数。
- 首次等待 15 秒；恢复失败按 15、30、60、120 秒递增重试，第五次及以后每 15 分钟重试。监控循环每 15 秒检查待恢复状态，实际启动可比倒计时稍晚。连接准备及每次列表、详情、热榜请求有 90 秒上限，清理各阶段最多 5 秒，避免异常浏览器无限占用任务锁；正常多页扫描不会被整体截断。
- 恢复取得全局页签锁，沿用 `dy` 浏览器档案与登录状态，不回退到新的登录上下文。只有带采集标记或记录 target ID 的采集页签会被关闭重建，用户浏览页签不被重置。target ID 保存在 `browser_data/douyin-collection-target.json`，浏览器重启后失效记录会被新采集页覆盖。
- 已保存的作品、快照和任务保留，恢复不删除、重置或重建数据库；后续继续调度符合执行窗口的待办任务，已经错过窗口的快照仍按现有规则处理，不伪造历史数据。
- 手动暂停、普通爬虫占用和风控冷却期间不启动恢复；恢复期间点击暂停仍然有效。登录失效必须在专用 Chrome 登录并点击“恢复监控”；自动恢复不代替登录或平台验证，也不缩短风控冷却。
- “采集控制”显示自动恢复状态、重试倒计时和次数；热榜在等待恢复时显示最近缓存。状态仅保存在当前后端进程；后端关闭期间无法恢复 Chrome。`CDP_CONNECT_EXISTING=True` 时仅尝试重连已有浏览器，不启动新 Chrome；需要关闭后自动重新启动时应使用默认管理模式。
- 浏览器进程完全无响应、操作系统资源耗尽或代理持续故障时，系统会继续退避重试并保留错误，不强杀用户 Chrome；可能需要人工排查。离线回归见 `tests/test_browser_recovery.py` 和 `tests/test_douyin_collection_page.py`。

```sh
uv sync --frozen
uv run --frozen pytest -q tests/test_douyin_browser_session.py tests/test_monitor_session_safety.py tests/test_monitor_repository.py tests/test_monitor_hot_rank.py
```

上述回归测试使用模拟浏览器与测试数据库，不需要真实登录凭据，也不会请求目标平台。
部署端曾验证作品详情、账号第二页，以及一轮 33 个快照完成、零失败和零重试；这仅是验证时点的结果，不保证未来平台访问持续可用。

该逻辑依赖正常网页和页面发出的接口响应。如果平台页面结构变化或要求验证，应保留错误和退避，检查正常登录与页面访问，不提高请求频率或绕过访问控制。
提交中不包含 Cookie、密码、签名值、运行日志、浏览器档案或生产数据库。
