# 热点洞察阅读体验优化（2026-11-03）

- 展示标题分离话题和明确署名，保留日期、政策括注等正文信息；原始采集文案不修改，可在详情中展开查看。
- 点击列表或星云作品自动进入阅读布局，选中项高亮并在列表内定位。标题、频道地域标签及最新互动指标位于阅读头部，正文独立滚动。长标题可展开。
- 标签判定证据与模型自评默认折叠；切换作品时重置展开状态。
- 热榜保留上次成功结果，在更新失败时继续显示缓存并提示更新时间。浏览器缓存最长保留 7 天，空结果及过期结果不覆盖成功缓存。自动请求超时 15 秒，手动刷新 25 秒；无缓存时显示错误和重试入口。

验证：前端 TypeScript/Vite 构建通过；`node scripts/test-reading-presentation.mjs` 覆盖标题清理、原文保留及缓存异常分支。浏览器验证选中联动、长标题按钮布局、依据与原文展开、切换作品后恢复折叠。

限制：当前热榜采集接口存在浏览器恢复故障，实际页面验证了无缓存失败状态；成功缓存恢复及校验通过针对性脚本验证。本次没有修改采集浏览器恢复流程。
