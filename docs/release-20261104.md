# 2026-11-04 release

This release publishes the current local account matrix, account profiles,
topic monitoring and simplified insights UI. Legacy event comparison,
opportunity, title-generation, editorial-draft and training-sample modules
are removed from the active application.

Account comment collection includes visible parent comments and replies,
resumable pagination, compact reading and updates after committed snapshots.
Interrupted snapshot jobs are reconciled under the shared browser lease.

Deployment preserves machine-specific configuration, databases and browser
login state. The deployment may supply RISK_CONTROL_MAX_COOLDOWN_SECONDS;
the target installation retains its existing three-hour cooldown ceiling.

Build with TypeScript and an explicit fresh Vite output directory; do not use
the shared-output build script during verification. Database files, credentials,
browser state, temporary evidence and build directories are excluded from Git.

Release checks include offline backend tests, frontend presentation/status
checks and isolated comment UI acceptance. Live platform collection and real
model inference are not release-test requirements and are not simulated as
successful production collection.
