# 标题质量优化 v0.2

日期：2026-10-29。已在本地应用，后端已重启，原监控及自动分析设置已恢复。本轮真实模型调用为 0。

## 功能变化

- 每个新标题包含角度枚举：核心事实、背景补充、时间地点、服务解读，以及具体信息重点。提示词要求优先不同信息重点，不以换词或换标签凑数量。
- 每个角度必须给出对应来源的逐字片段，服务端验证来源、片段和哈希绑定。服务解读必须在所引片段和标题中均有可操作的服务表达；材料不足允许少于 3 条或没有结果，不补模板、不自动重试。
- 标题文字规范化后，综合对称序列相似度、二元字组重叠及包含关系，取最大值。与此前保留标题的相似度达到 80% 时过滤。页面显示生成数、保留数、角度、过滤原因及原候选序号。
- 从当前有效账号档案读取标题结构、措辞习惯、受众表达特征，服务端生成绑定档案 SHA 的特征 ID。模型只能声明这些特征，并给出当前标题中的逐字片段；页面原位展开显示特征、档案摘要、对应标题片段及档案绑定。
- 未提供有效采用说明时，不宣称采用了账号风格。风格依据和质量检查默认折叠。

## 限制与下一步

- 字面相似度不能穷尽同义改写，也可能过滤文字接近但角度有差别的标题。80% 是过滤阈值，不是命中率或准确率；按模型输出顺序保留。
- 角度归类仍是模型解读。逐字引用验证、服务关键词与时间窄校验不等于语义或全文事实核验，也不能保证所有关键限定都被模型保留。
- 风格采用属于模型声明、片段可定位；不代表已独立证实风格符合度。未训练专用模型，不宣称训练成效。
- 本轮隔离数据、模型响应与图片均为模拟；测试中的日期不是当天真实作品的验收日期。本轮未消耗真实模型预算，尚不能宣称真实标题质量提升已经实测。
- 下一步由编辑选择一条近期真实线索，主动生成并检查角度差异、关键限定、风格依据及过滤说明。旧缓存不会自动升级，重新生成仍沿用原有显式请求与预算限制。
