# 话题监控采集 v0.1

日期：2026-11-02。范围：本地项目新增独立「话题监控」页面，支持关键词历史补采与未来持续监控。已切换本地运行版本，未替用户创建真实话题任务。

## 使用方式

1. 进入侧栏「话题监控」，点击「新增话题」。
2. 填写名称，例如「第39届中国电影金鸡奖」；填写一个或多个搜索关键词，换行或逗号分隔。
3. 选择「未来两周」「过去一周＋未来一周」「过去一周」，或调整自定义开始/结束时间。
4. 设置采集间隔、每关键词每轮页数，以及是否创建后立即启用。
5. 启用后由独立调度器采集；可随时单独暂停话题。采集总开关暂停、浏览器恢复或风控冷却时安全等待。

时间窗口约束作品发布时间，开始包含、结束不包含；不是采集进程必须连续运行的时长。未来作品发布后才能发现。窗口结束后完成一次成功的最终搜索即停止。更改名称、关键词或时间窗口需创建新监控，避免旧数据与新范围混杂。当前可通过接口修改间隔、页数及启停，页面提供启停。

## 账号监控与话题监控共存

- 两类模块可同时启用，各自独立调度与保存；不要求关闭账号监控才能采集话题。
- 共用现有采集互斥锁和跨进程专用浏览器租约。平台请求分轮执行，不并行争抢登录页签。
- 浏览器忙时，话题本轮返回等待，不创建失败轮次、不推进该话题采集时间；空闲后继续检查。页面显示等待状态。
- 话题每轮最多运行480秒；连续搜索请求之间等待5秒，等待可响应停止。
- 每次调度最多实际采集一个话题，优先从未尝试/较久未尝试的话题。实际采集后留出65秒空闲窗口，覆盖账号监控的60秒轮询周期；等待时每15秒重查。
- 账号发现或快照遇到话题占用，保留原调度信息，后续账号轮询继续执行。共享浏览器意味着存在排队延迟，不保证两种请求在同一时刻完成，也不保证高负荷下快照无延迟。
- 单独暂停一个话题不暂停账号；单独禁用一个账号不暂停话题。采集总开关、登录异常和平台风控仍统一生效。
- 不改变已有账号发现、快照和冷却参数，不把搜索作者自动加入账号矩阵。

## 展示与计算口径

| 内容 | 实现及边界 |
| --- | --- |
| 作品发布趋势 | 按北京时间发布日期汇总已采集作品，非曝光趋势 |
| 热度话题排行 | 从文案提取话题标签，按关联作品累计互动之和排序；最多显示15个，不代表语义事件聚类 |
| 高热度作品 | 按累计互动、最近发布或可比较的互动增量排序，每页10条 |
| 原始互动 | 展示点赞、评论、收藏、分享及采集时间；缺失为 —，真实0保留0 |
| 累计互动 | 对有效的已有计数求和；四项全缺失则为空，部分缺失明确标注 |
| 样本热度 | 累计互动在当前话题样本中的对数归一指数，0—100；不是播放量、全平台或官方热度 |
| 观测增量 | 仅比较同作品不同采集时间的两次四项完整且未回落计数；缺失、回落均不补0 |
| 观察状态 | 至少2轮成功观测、跨度至少24小时且至少5条作品后，以近24小时与前24小时发布量观察上升/退潮/持续发酵；不足则如实显示数据不足 |

状态准备度使用全部成功轮次的聚合，不受页面仅显示最近20轮采集记录影响。当前不调用模型、不做热点预测、不承诺预测命中率。话题搜索采用最新排序、文案字面命中与发布窗口过滤；任一关键词命中即可，不能作为同事件的语义确认。

## 文件与接口

| 文件 | 用途 |
| --- | --- |
| database/topic_monitor_repository.py | 独立话题配置、作品关联、轮次与观测存储 |
| api/services/topic_monitor_service.py | 校验、有限关键词采集、调度、共存与热度计算 |
| api/routers/topic_monitor.py | 新增话题接口 |
| api/main.py | 注册路由及启动/关闭话题调度器 |
| webui/src/lib/topicMonitor.ts | 类型与API客户端 |
| webui/src/components/monitor/TopicMonitor.tsx | 话题配置、图表、作品列表与等待状态 |
| webui/src/App.tsx | 独立侧栏入口与懒加载页面 |
| tests/test_topic_monitor.py | 隔离后端及双监控共存测试 |
| tools/accept_topic_monitor.py | 隔离浏览器验收 |

接口：GET/POST `/api/topic-monitors`、GET/PUT `/api/topic-monitors/{id}`。修改使用 expected_version 校验，冲突返回409。列表和详情GET不建库、不写入、不触发采集。

数据存于原库旁独立 `topic_monitor.db`：5张表、2个索引。仅用户显式创建首个话题时初始化；启动、读取及空调度不创建文件。原账号作品库不新增表。每轮最多保存500条，全部话题最多5万条作品、50个任务；达到上限明确失败，不静默截断。观测持续追加，尚未提供归档与清理界面。

## 已知限制与下一步

历史结果受平台搜索排序、关键词和页数限制；高互动作品可能未召回。增量仅对再次出现在搜索结果中的作品形成，尚未对全部已发现话题作品独立持续刷新快照。该指数不能替代统一生命周期竞品对比。

本轮未验证真实平台搜索可用性、登录兼容性及真实召回质量。下一步可由用户创建一个低频、少关键词的真实任务，观察首轮匹配作品、缺失计数、页数上限及账号快照的共同运行情况，再决定是否接入语义归类、自动选题和训练样本链路。当前模块没有主动模型请求。
