# 同事件竞品对比 v0.3

日期：2026-10-23。

## 本次变更

- `api/services/event_comparison_service.py`：升级为 `manual-event-comparison-v0.3`。按双方清理后的发布文案生成确定性的原文片段目录，模型只选择 `side + segment_id`；服务端校验片段所属方并回填逐字原文、来源身份及SHA。不存在或跨方的ID拒绝，不模糊匹配、不自动修复、不重试。
- 引用片段按标点及换行划分，最长300码点；长片段再顺序切分。ID仅在当前绑定输入中有效，不作为跨输入持久身份。预算检查包含片段目录。
- 总体判断为 `different_angles` 必须有 `angle` 条目；有 `angle` 条目必须判断为 `different_angles`。`insufficient_material` 不允许附带差异条目。事实补充与背景补充可与“无明显角度差异”并存。矛盾结果记录 `assessment_category_inconsistent` 并返回既有502错误，不擅自改写模型判断。
- 提示词明确演习代号、行动名称及已有部署事实中的装备全称通常属于背景细节；核心事实应改变事件进展、结果、行为或关键数量。不从距离或措辞推断作者意图。该部分是语义指令，不宣称服务端能自动证明分类正确。
- 保留单次显式模型请求、严格校验、失败保留页面已有有效结果、模型结束后输入绑定重检及脱敏分类日志。新日志类别 `segment_reference_invalid` 用于不存在或跨方的片段ID。
- 对外请求与响应结构不变：模型内部的片段ID不会替换页面已有的原文引用展示。只读基础对比不调用模型。
- `tests/test_event_comparison.py`：调整模型替身并增加片段恢复、SHA、确定性、长文切分、跨方ID和总体判断一致性测试。
- `tools/accept_event_comparison.py`：验证无角度差异但有事实补充的展示，以及矛盾输出拒绝后保留上一份有效结果。

## 限制与应用

片段ID消除模型抄写引文造成的不一致，但不能证明推断或事实正确；模型仍可能选错片段或语义分类错误，需要编辑复核。旧模型输出格式不做兼容回退，以免静默失去新约束。

本次未重启运行中的后端。重启后端后生效，前端可继续使用现有v0.2构建。建议之后显式重验原两组作品，核对事实细节/背景与实质角度的边界。不要将模拟测试通过表述为真实模型分类质量已验证。

回滚仅定向恢复本次服务及测试修改；不全局恢复工作区，不改数据库或既有证据。
