# 融媒智策界面重建（2026-11-03）

以用户提供的 design.md、MASTER.md 为设计参考，主要依据「融媒智策_深浅切换 (1).html」重建应用外壳与热点洞察首页。参考文件中的说明仅作为设计材料。

## 新结构

- SpatialHeader：品牌、主导航、模块/内容搜索、账号上下文、深浅主题与管理入口。
- SpatialInsights：日期回溯、内容线索、星云/弹幕、内容详情、平台热榜；直接使用现有监控接口和账号上下文。
- spatial.css 与 design-tokens.css：新的空间布局、蓝色玻璃面板、语义主题变量和响应式规则。
- business-layout.css：保留业务图表、报表、表格所需的专用几何规则；原有模块在新的工作区框架下继续使用。
- public/spatial：从主参考 HTML 提取的品牌及背景资源。

原有账号、话题、内容分析、任务、热榜、导出与采集配置的 API 和业务逻辑继续使用。首页默认进入热点洞察，已有 tab/module 链接仍可访问。本次没有修改后端，也没有覆盖现有业务开发改动。

## 验证

- `cd webui` 后运行 `npm run build -- --outDir dist-spatial-rebuild`，TypeScript 与 Vite 构建通过。输出独立于 api/webui。
- 本地预览：`npm run dev -- --host 127.0.0.1 --port 5174 --strictPort`。
- 浏览器使用实际账号与 1204 条作品数据检查主题切换、搜索/筛选、内容详情、星云/弹幕和展开视图；检查账号矩阵、话题监控、内容工作台、运行总览、任务中心、热榜、导出与设置的只读入口。
- 检查 1440×900 与 375×812 布局。没有执行删除、保存配置、启动采集或生成报告等业务操作。
- 构建仍提示 Browserslist 数据较旧和主包超过 500 kB；不影响此次构建通过。

本次彻底重建的是应用外壳、主题系统和洞察首页；复杂业务模块沿用原有内部组件并接入新视觉框架，尚未逐一重写其全部交互。
