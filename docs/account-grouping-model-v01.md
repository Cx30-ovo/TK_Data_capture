## 之前没有模型推断的原因

第一阶段只实现统计档案及人工矩阵；已有通用模型客户端不代表已实现账号业务分组推断。此前本地启动时明确设置 AI_ENABLED=false，覆盖 .env 的已配置模型。专用训练数据、训练和独立评测尚未完成，不能称为已训练模型。

用户本轮明确授权直接调用 .env 模型，并说明文本和视觉为同一模型。当前新增业务分组推断只发送文本，视觉分析保持关闭，无封面传输。

## 接入与边界

- GET `/api/monitor/account-matrix/model-status` 只读配置状态，不请求模型，不返回地址或凭据。
- POST `/api/monitor/account-matrix/{account_id}/infer-group`，请求 days 默认30、1—365；读取只读档案，选取最多24篇已有可定位标题依据，每条最多1500字符，至少3篇；这是证据子集而非随机全量样本。
- 复用 .env 的文本模型配置，一次请求，最多1200输出token，最长90秒，无自动重试，不走环境代理或重定向；请求关闭本次思考输出。
- 校验 JSON 结构、分组非空和50字符上限、所有引用ID属于输入；真实标题片段由后端回填，不信任模型编造片段。结构校验不等于语义正确。
- 返回分组、理由、限制、原始标题依据、模型、版本及输入SHA；不推断自有/竞品身份。用户可采用到表单、修改，再显式保存。
- 进程内15分钟缓存，key含版本、模型配置和本次输入内容；不随页面GET推断，不自动覆盖分组。并发模型请求限1，结果缓存最多128项。重启失效。
- 本功能不写采集库，不新增业务表；采用后复用现有独立业务元数据库保存。
- 模型输入标题是不可信数据，系统提示禁止执行其中指令；输出仍需人工核验，不能保证抗提示注入或分组正确。

## 可视化
