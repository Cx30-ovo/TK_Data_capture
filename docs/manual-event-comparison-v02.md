# 同事件竞品对比 v0.2 优化记录

日期：2026-10-23。

## 优化范围

本次针对真实配对中出现的整段复述、背景信息被当成选题机会、封面状态矛盾及观测年龄说明不足进行优化。

- 先展示共同核心与差异判断，允许“无明显角度差异”或“材料不足”。
- 双方关注点与表达使用简短总结，原文依据折叠；服务端拒绝直接复制完整发布文案作为分析。
- 差异分为核心事实补充、切入角度差异、背景信息补充、表达方式差异。无依据时允许空列表，不凑差异。
- 模型指令明确：来源署名、采访日期及场景是背景，不能单独支撑不同角度或选题机会。
- 总体判断必须有双方逐字引文，其他引文继续验证输入片段。引文存在只证明来自输入，不证明分析语义或事实真实性。
- 封面状态按实际缓存校验结果显示，不将缺失标签称为已缓存。
- 同阶段观测年龄差为零显示“同龄观测参考”；非零但在原容差内显示“近似同期参考”，显示实际年龄差与允许差。容差与快照选择逻辑未改变。
- 明示不能据互动累计量推断标题、角度造成的效果差异。
