# 频道与地域自动规则分类

日期：2026-11-10。规则版本：`editorial-rules-v3.0`。

## 本轮结果

频道与地域改为读取时自动计算，使用文案规则、地点词典及冲突处理，不再进入 AI 复核队列，不读取人工纠错经验，不加载图片或视频。界面移除人工纠正入口和 AI／人工复核状态标签，展示分类依据；依据不足或冲突时保留“待判定”。

仅调整频道／地域分类。账号风格档案等其他模型功能不在本轮范围内。

本轮未调用模型、访问平台、写入正式数据库或执行迁移，未提交、推送、部署到远端或访问 Mac mini。测试写入仅发生于独立测试数据库。

## 规则与数据边界

1. 使用原始标题字段及发布文案。去重相同输入，排除来源、人员署名、链接等元数据；命中片段保持为原文字串。
2. 优先识别事件和行为组合，普通关键词为弱线索；话题标签可补充已有线索，不能独立建立分类。
3. 家庭日常、校园怀旧等用组合规则区分，避免只因出现“宝宝”“学校”等词直接划类。明确医疗、教学、司法等上下文优先。
4. 地域分为本地（厦门）、本省（福建省级及省内其他城市）、国内（含港澳台）、国际。识别有限地名与别名，排除籍贯、来源、机构和人物等背景线索；多地域竞争或歧义地点无法解决时保留待判定。
5. 提供字段、原文片段、规则 ID、候选、权重和版本。权重是规则内部排序依据，不是准确率、概率或事实核验结论。
6. 既有 AI 分类、人工纠正记录保持原样，但不再参与当前分类。新旧作品都在读取时应用当前规则，无数据回填。

## 真实数据只读覆盖检查

本地 1,596 条作品采用 SQLite 只读连接和 `query_only` 检查：频道待判定 873 条，地域待判定 704 条；全部规则片段均可对应原文，片段不一致数为 0。

该检查没有人工标注的正确答案，只能说明覆盖率和依据一致性，不能作为准确率。词典和上下文规则仍有限，可能漏判或误判；不通过强行填充标签掩盖线索不足。
