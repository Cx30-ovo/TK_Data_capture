# 同事件竞品对比与事件机会池移除

2026-11-03，按用户授权移除这两个模块，以及其标题生成、自动选题、草稿、编辑反馈和训练样本功能。用户随后明确要求删除相关数据库，不保留运行数据。

## 实现范围

- 删除 22 个专属后端服务、10 个前端组件、5 个 API/类型客户端、18 个专属测试、4 个验收/审计工具，共 59 个文件。逐文件清单见 `tmp/remove-event-modules-20261103-01/removal-manifest.json`。
- `api/routers/monitor.py` 撤销这条链路的所有端点与专属参数验证辅助函数。
- `api/main.py` 移除自动竞品分析与自动选题 runner 的导入、启动及停止钩子。
- `webui/src/App.tsx` 移除导航、路由类型、惰性加载和页面；旧页面深链回到运营总览。
- `AccountMatrix.tsx` 保留账号身份和关联管理，文案调整为“关联竞品”，删除自动同事件分析暗示。
- 中英文导航文案移除旧入口。
- 更新账号矩阵验收，核对新文案、旧深链与无已删除 API 请求。
- `pyproject.toml` 指定 `testpaths = ["tests"]`。默认发现此前会扫描 tmp 中的历史测试副本并产生导入错误，现仅收集当前测试。

账号矩阵、账号档案/风格、账号监控、话题监控、原有内容表现/内容雷达/分析服务均保留。共用的 `title_sentence.py` 及标题统计逻辑仍服务账号档案，保留。

## 数据清理与运行切换

先停用旧自动发现/分析，确认无在途分析，再安全暂停采集，核实所有相关执行者空闲。仅停止已验证属于本项目的后端与自动重启进程；浏览器和前端开发服务不停止。

删除三份实际存在的运行数据库：

- `database/automatic_comparisons.db`
- `database/comparison_automation.db`：同时包含标题请求、自动选题及草稿记录。
- `database/event_candidate_runs.db`

专属 `database/event_feedback.db` 当时不存在，核对其及关联 SQLite 日志均未遗留。不创建被删除数据库的恢复副本。本次清理运行数据库，不清理历史 tmp 验收档案中的隔离测试库或旧证据。

`database/sqlite_tables.db`、`database/account_matrix.db`、`database/topic_monitor.db` 三份保留库在清理与服务重启前后 SHA 完全一致。操作前话题任务列表已为空，操作后仍为空，未因清理丢失任务。

独立构建 `webui/dist-remove-events-20261103-01`，构建前后共享目录路径与 SHA 一致；之后单独应用 39 个资源，删除共享静态目录中 1565 个已过时构建文件，避免继续保留旧功能可加载块。恢复原本地后端启动方式，监听 loopback。未访问 Mac mini，未提交、推送或远程部署。
